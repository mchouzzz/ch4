01網站初步規劃

我提出的需求

請幫我為慈濟大學經營管理學系設計一個新的系所網頁，並參考原本系所網站的內容。希望網站具有正式、專業的形象，且 HTML、CSS 和 JavaScript 都能整合在網頁檔案中。

ChatGPT 的建議

建議將網站分成系所介紹、教育目標、課程特色及學生作品等區塊。使用 HTML 建立網站架構，CSS 負責視覺設計，JavaScript 增加互動效果，讓網站更完整。

02調整網站設計風格

我提出的需求

請幫我將網站改成專業學術又帶有可愛 Q 版元素的設計。

ChatGPT 的建議

保留正式系網的內容架構，加入柔和色彩、圓角區塊、卡片式排版及簡單的互動效果，兼顧專業性與親切感。

我再次調整需求

我想要粉色系的風格，並希望參考日本設計相關科系的網站，整體簡單、簡約一點。

ChatGPT 的建議

將網站調整為低飽和粉色搭配白色背景，運用日系簡約設計中的留白、整齊排版與柔和配色，減少多餘裝飾。

03建立網站檔案架構

我提出的需求

老師要求網站至少有兩個頁面，分別是 index.html（系所介紹）及 studentworks.html（學生作品），所有圖片與影片都放在 graph 資料夾內，請幫我重新製作。

ChatGPT 的建議
  • index.html：系所介紹首頁，包含系所特色、教育目標及相關介紹。
  • studentworks.html：學生作品展示頁，預留未來新增作品、照片及影片的空間。
  • graph：集中存放網站使用的圖片及影片素材。

兩個頁面使用相對路徑連結，CSS 與 JavaScript 寫在各自 HTML 檔案內，方便後續編輯及發布。

04檢查網站是否正常運作

我提出的需求

可以再幫我確認一次這個網站確定是可以使用的嗎？

ChatGPT 的建議

說明應檢查 HTML 基本架構、頁面導覽、圖片路徑及響應式版面設計，並建議使用 Chrome 或 Edge 開啟 HTML 進行測試。

05解決跨頁連結問題

我遇到的問題

我的首頁 index.html 點不進學生作品頁面。

ChatGPT 的建議

確認兩個 HTML 檔案放在同一層資料夾，並將首頁連結設定為：

<a href="./studentworks.html">學生作品</a>

學生作品頁返回首頁則使用：

<a href="./index.html">返回首頁</a>

檢查檔名與大小寫是否一致，避免因相對路徑錯誤出現 404。

06GitHub 網站上架

我提出的問題

我要上傳 GitHub，是要上傳哪一些檔案？

ChatGPT 的建議

需上傳 index.html、studentworks.html，以及整個 graph 資料夾，並保留原本的資料夾結構。

接著將 Repository 設為 Public，進入 Settings → Pages，選擇 Deploy from a branch，Branch 選擇 main、資料夾選擇 /(root) 並儲存。發布成功後，以 GitHub Pages 提供的網址檢查兩頁能否正常瀏覽。

07AI 協作心得

這次系網頁設計過程中，我主要利用 ChatGPT 協助規劃網站架構、設計視覺風格、產生 HTML 程式碼，以及解決網頁連結的問題。

一開始對 HTML 和 CSS 的運用還不太熟悉，因此透過不斷提出需求及修改，逐漸了解網頁的基本架構，以及檔案名稱、資料夾位置和相對路徑的重要性。

在設計方面，我希望網站不只是完成作業，而是真的具有系所網站的專業形象，所以選擇粉色系搭配日式簡約風格，讓畫面更加清楚，也保有自己的設計特色。

透過這次 AI 協作，我學習到如何將自己的設計想法轉換成實際的網頁，也了解遇到程式問題時，可以透過檢查與修改逐步改善。未來也希望能加入自己拍攝的照片、影片和學生作品，讓網站內容更加完整。
